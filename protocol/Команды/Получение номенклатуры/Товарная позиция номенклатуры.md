# Товарная позиция номенклатуры (NomenclatureResponse::Item)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| article | Артикул | string | нет |  |
| barcode | Штрих код | string | нет | Обязательно при ntin== null |
| ntin | Штрих код | string | нет | Обязательно при barcode == null |
| description | Описание позиции | string | нет |  |
| purchase_price | Цена закупки | [Money](../../Общие%20типы%20данных/Деньги.md) | да, нет версии 2.0.3 |  |
| sell_price | Цена продажи | [Money](../../Общие%20типы%20данных/Деньги.md) | да, нет с версии 2.0.3 |  |
| discount_percent | Процент скидки | uint32 | нет | Процент скидки на товар |
| discount_sum | Сумма скидки | [Money](../../Общие%20типы%20данных/Деньги.md) | нет | Сумма скидки на товар |
| markup_percent | Процент наценки | uint32 | нет | Процент наценки на товар |
| markup_sum | Сумма наценки | [Money](../../Общие%20типы%20данных/Деньги.md) | нет | Сумма наценки на товар |
| taxes | Налоги | List<[NomenclatureResponse::Tax](Налог%20элемента%20номенклатуры.md)> | 0…n | n == [TaxTypeEnum](../../Общие%20типы%20данных/Типы%20налогов.md)::size |
| measure_count | Количество единиц измерения | uint32 | нет | В тысячных долях<br>Например, если имеется товар, расфасованный по 100 грамм, тогда:<br>- если measure_title= «граммы», то measure_count=100000<br>- если measure_title= «килограммы», то measure_count=1000 |
| measure_title | Наименование единицы измерения | string | нет |  |
| measure_fractional | Признак, является ли единица измерения дробной | bool | нет | Например, килограммы – дробная, штуки – нет. |
| measure_unit_code | Код единицы измерения | string | нет | Код единицы измерения в ИС ЭСФ |
| is_markedeac | Признак маркировки | bool | нет | Для товаров подлежащих обязательной маркировки |
| is_social | Признак социально значимого потребительского товара | bool | нет | Для товаров относящихся к СЗПТ |

### Спецификация на уровне Protobuf

Имя файла: [nomenclature.proto](../../../proto/nomenclature.proto)

```protobuf
message Item  {
    optional string article = 1;
    optional string barcode = 2;
    optional string description = 3;
    optional Money purchase_price = 6; // optional с версии 203
    optional Money sell_price = 7; // optional с версии 203
    optional uint32 discount_percent = 8;
    optional Money discount_sum = 9;
    optional uint32 markup_percent = 10;
    optional Money markup_sum = 11;
    repeated Tax taxes = 12;
    optional uint32 measure_count = 13;
    optional string measure_title = 14;
    optional bool measure_fractional = 15;
    optional string measure_unit_code = 16; // добавлено в версии 201
    optional string ntin = 17; // добавлено в версии 203
    optional bool is_markedeac = 18; // добавлено в версии 203
    optional bool is_social = 19; // добавлено в версии 203
  }
```
