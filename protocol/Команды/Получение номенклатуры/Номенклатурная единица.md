# Номенклатурная единица (NomenclatureResponse::Element)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Тип элемента | [ElementTypeEnum](Тип%20элемента%20номенклатуры.md) | да |  |
| title | Название товара, работы, услуги/группы | string | да | На русском языке |
| title_kk | Название товара, работы, услуги/группы | string | нет | На казахском языке |
| parent_group_id | ID родительской группы | uint64 | нет | id родительской группы, у корневого элемента отсутствует. |
| id | ID элемента | uint64 | да |  |
| item | описание товара | [NomenclatureResponse::Item](Товарная%20позиция%20номенклатуры.md) | нет (см. примечания) | если type== ITEM, то обязательно |

### Спецификация на уровне Protobuf

Имя файла: [nomenclature.proto](../../../proto/nomenclature.proto)

```protobuf
message Element {
    required ElementTypeEnum type = 1;
    required string title = 3;
    optional string title_kk = 7; // добавлено в версии 203
    optional uint64 parent_group_id = 4;
    required uint64 id = 5;
    optional Item item = 6; // required при type == ITEM
  }
```
