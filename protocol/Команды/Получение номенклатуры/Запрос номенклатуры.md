# Запрос номенклатуры (NomenclatureRequest)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| current_version | Текущая версия | uint32 | да, для версии ниже 2.0.3 | Если номенклатуры на устройстве нет, то current_version=0 |
| barcode | Штрих код | string | нет | В данном поле ККМ передаёт либо GTIN либо NTIN. |

### Спецификация на уровне Protobuf

Имя файла: [nomenclature.proto](../../../proto/nomenclature.proto)

```protobuf
message NomenclatureRequest {
  optional uint32 current_version = 1; // optional с версии 203
  optional string barcode = 2; // добавлено в версии 203
}
```
