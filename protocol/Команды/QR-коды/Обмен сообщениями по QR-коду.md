# Обмен сообщениями для проведения платежа по QR-коду

Раздел описывает механизм работы с мобильными платежами по QR-коду в версии протокола 2.0.4.

Система позволяет получить **QR-код по запросу из системы мгновенных платежей** для проведения мобильного платежа по QR-коду, а также отслеживать статус прохождения платежа.

---

## 1. Запрос генерации и статуса QR-кода

Для взаимодействия используются две новые команды:
* **`COMMAND_QR_GENERATE` (100)** — отправка запроса на формирование QR-кода на сервере.
* **`COMMAND_QR_GET_STATUS` (101)** — периодический запрос статуса оплаты сформированного QR-кода.

### Коды команд

| Название | Код команды | Описание |
| --- | --- | --- |
| Генерация QR-кода | `COMMAND_QR_GENERATE` (100) | Запрос на создание QR-кода для оплаты в системе мгновенных платежей. |
| Статус платежа | `COMMAND_QR_GET_STATUS` (101) | Проверка статуса платежа по созданному QR-коду. |

---

## 2. Структура запроса к серверу (`QRRequest`)

Имя файла: [qr.proto](../../../proto/qr.proto)

```protobuf
message QRRequest {
  required uint64 invoice_id = 1;
  optional Money amount = 2; // required при COMMAND_QR_GENERATE
}
```

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| `invoice_id` | Номер транзакции | `uint64` | да | Уникальный номер инвойса/транзакции |
| `amount` | Сумма платежа | `Money` | нет(*) | (*) Обязательно передается при команде `COMMAND_QR_GENERATE` |

---

## 3. Структура ответа сервера (`QRResponse`)

Имя файла: [qr.proto](../../../proto/qr.proto)

```protobuf
message QRResponse {
  required string qr_code = 1;
  required StatusTypeEnum status = 2;
}
```

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| `qr_code` | QR-код | `string` | да | Содержит данные участника платежа для генерации графического QR-кода |
| `status` | Статус платежа | `StatusTypeEnum` | да | Текущее состояние процесса оплаты по QR-коду |

---

## 4. Коды статусов платежа (`StatusTypeEnum`)

```protobuf
enum StatusTypeEnum {
  STATUS_NEW = 0;
  STATUS_SCANNED = 1;
  STATUS_BLOCKED = 2;
  STATUS_AUTH = 3;
  STATUS_PAID = 4;
  STATUS_REJECTED = 5;
  STATUS_WAIT = 6;
}
```

| Код | Значение | Описание |
| --- | --- | --- |
| `0` | `STATUS_NEW` | QR-код успешно сгенерирован |
| `1` | `STATUS_SCANNED` | QR-код считан покупателем |
| `2` | `STATUS_BLOCKED` | QR-код заблокирован |
| `3` | `STATUS_AUTH` | Происходит авторизация платежа по QR-коду |
| `4` | `STATUS_PAID` | Платеж по QR-коду успешно прошел |
| `5` | `STATUS_REJECTED` | Платеж по QR-коду отклонен |
| `6` | `STATUS_WAIT` | Ожидается проведение платежа по QR-коду |
