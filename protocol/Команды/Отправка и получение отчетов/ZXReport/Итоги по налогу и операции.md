# Итоги по налогу и операции (ZXReport::Tax::TaxOperation)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| operation | Тип операции | [OperationTypeEnum](../../../Общие%20типы%20данных/Операции%20с%20чеком.md) | да |  |
| turnover | Итоговая сумма по операциям, облагаемым налогом | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| turnover_without_tax | Итоговая сумма по операциям, без учета налога | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| sum | Сумма налога | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
