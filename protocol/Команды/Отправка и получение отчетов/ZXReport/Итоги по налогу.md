# Итоги по налогу (ZXReport::Tax)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Тип налога | [TaxTypeEnum](../../../Общие%20типы%20данных/Типы%20налогов.md) | да |  |
| percent | Значение налога в процентах | uint32 | да | В тысячных долях, например 12000 == 12,0% |
| operations | Итоги по операциям по данному налогу | List<[ZXReport::Tax::TaxOperation](Итоги%20по%20налогу%20и%20операции.md)> | n | n == [OperationTypeEnum](../../../Общие%20типы%20данных/Операции%20с%20чеком.md)::size |

### Спецификация на уровне Protobuf

Имя файла: [report.proto](../../../../proto/report.proto)

```protobuf
message Tax {
    message TaxOperation {
      required OperationTypeEnum operation = 1;
      required Money turnover = 2;
      required Money sum = 3;
      required Money turnover_without_tax = 4; // добавлено в версии 200
    }

    required TaxTypeEnum type = 1;
    required uint32 percent = 2;
    repeated TaxOperation operations = 3;
  }
```
