# Итоги по чекам (ZXReport::TicketOperation)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| operation | Тип операции | [OperationTypeEnum](../../../Общие%20типы%20данных/Операции%20с%20чеком.md) | да |  |
| tickets_total_count | Общее количество чеков по данной операции | uint32 | да |  |
| tickets_count | Количество чеков по данной операции за смену | uint32 | да |  |
| tickets_sum | Сумма по чекам по данной операции за смену | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| payments | Итоги по видам расчетов | List<[ZXReport::TicketOperation::Payment](Итоги%20по%20расчетам.md)> | n | n == [PaymentTypeEnum](../../../Общие%20типы%20данных/Типы%20оплат.md)::size |
| offline_count | Количество чеков за смену в автономном режиме | uint32 | да, для протокола версии 2.0.2 и выше. |  |
| discount_sum | Сумма скидки по всем чекам за смену | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| markup_sum | Сумма наценки по всем чекам за смену | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| change_sum | Сумма сдачи по всем чекам за смену | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |

### Спецификация на уровне Protobuf

Имя файла: [report.proto](../../../../proto/report.proto)

```protobuf
message TicketOperation {
    message Payment {
      required PaymentTypeEnum payment = 1;
      required Money sum = 2;
      required uint32 count = 3; // required с версии 200
    }

    required OperationTypeEnum operation = 1;
    required uint32 tickets_total_count = 2;
    required uint32 tickets_count = 3;
    required Money tickets_sum = 4;
    repeated Payment payments = 5;
    required uint32 offline_count = 6; // required с версии 200
    required Money discount_sum = 7; // required с версии 200
    required Money markup_sum = 8; // required с версии 200
    required Money change_sum = 9; // required с версии 200
  }
```
