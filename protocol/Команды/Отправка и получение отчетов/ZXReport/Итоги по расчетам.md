# Итоги по расчетам (ZXReport::TicketOperation::Payment)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| payment | Вид расчетов | [PaymentTypeEnum](../../../Общие%20типы%20данных/Типы%20оплат.md) | да | То же, что «Вид оплаты» в чеке. |
| sum | Сумма по данному виду расчетов | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| count | Количество платежей | uint32 | да, для протокола версии 2.0.2 и выше. |  |

### Спецификация на уровне Protobuf

Имя файла: [report.proto](../../../../proto/report.proto)

```protobuf
message Payment {
      required PaymentTypeEnum payment = 1;
      required Money sum = 2;
      required uint32 count = 3; // required с версии 200
    }
```
