# Ответ сервера с отчетом (ReportResponse)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| report | Тип отчета | [ReportTypeEnum](Типы%20отчетов.md) | да | REPORT_X, если на настоящий момент смена открыта<br>REPORT_Z, если на настоящий момент смена не открыта |
| zx_report | Данные X\Z отчета | [ZXReport](ZXReport/Основная%20часть%20ZX-отчета.md) | да | Текущий X отчет, если смена открыта (report = REPORT_X), или же последний снятый Z отчёт, если открытой смены нет (report = REPORT_Z) |

# Ответ сервера с отчетом (ReportResponse)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| report | Тип отчета | [ReportTypeEnum](Типы%20отчетов.md) | да | То же значение, что и при отправке на сервер |
| zx_report | Данные X или Z отчета | [ZXReport](ZXReport/Основная%20часть%20ZX-отчета.md) | да | В этом поле всегда будет отчет.<br>Если был запрошен Z-отчёт, но это первая смена и еще нет ни одного Z отчета, то в ответ будет возвращён пустой отчёт, у которого проставлен номер смены 0 и дата, скопированные из запроса. |

### Спецификация на уровне Protobuf

Имя файла: [report.proto](../../../proto/report.proto)

```protobuf
message ReportResponse {
  required ReportTypeEnum report = 1;
  required ZXReport zx_report = 2;
}
```
