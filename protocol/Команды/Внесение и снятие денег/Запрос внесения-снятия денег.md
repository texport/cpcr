# Запрос внесения/снятия денег (MoneyPlacementRequest)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| date_time | Дата и время операции | [DateTime](../../Общие%20типы%20данных/Дата%20и%20время.md) | да |  |
| operation | Тип операции | [MoneyPlacementEnum](Тип%20операции%20внесения-снятия.md) | да |  |
| sum | Сумма | [Money](../../Общие%20типы%20данных/Деньги.md) | да |  |
| is_offline | Происходила ли операция внесения/снятия в автономном  режиме | bool | нет | Если поле отсутствует, то считается, что операция происходила в нормальном режиме |
| fr_shift_number | Номер текущей смены, считанный с ФР | uint32 | нет | Если поле отсутствует, сервер самостоятельно вычисляет номер смены |
| printed_document_number | Номер печатного документа | uint64 | нет | Номер, определяемый в рамках собственной пользовательской нумерации печатных документов. |
| operator | Оператор-кассир | [Operator](../../Общие%20типы%20данных/Сведения%20об%20операторе-кассире.md) | да |  |

### Спецификация на уровне Protobuf

Имя файла: [placement.proto](../../../proto/placement.proto)

```protobuf
message MoneyPlacementRequest {
  required DateTime date_time = 1;
  required MoneyPlacementEnum operation = 2;
  required Money sum = 3;
  optional bool is_offline = 4;
  optional uint32 fr_shift_number = 5;
  optional uint64 printed_document_number = 6; // добавлено в версии 200
  required Operator operator = 7; // добавлено в версии 202
}
```
