# Ответ сервера на чек (TicketResponse)

| Поле          | Наименование | Тип данных | Обязательно                           | Примечания                       |
| ------------- | ------------ | ---------- | ------------------------------------- | -------------------------------- |
| ticket_number | Номер чека   | String     | да                                    |                                  |
| qr_code       | QR код       | bytes      | да (для определенных видов устройств) | Для определенных видов устройств |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../proto/ticket.proto)

```protobuf
message TicketResponse {
  required string ticket_number = 1;
  optional bytes qr_code = 2;
}
```
