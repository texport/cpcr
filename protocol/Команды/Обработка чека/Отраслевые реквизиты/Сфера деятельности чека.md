# Отраслевые реквизиты

# Сфера деятельности чека (TicketRequest::Domain)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Вид отрасли | [DomainTypeEnum](../../../Общие%20типы%20данных/Вид%20отрасли.md) | да |  |
| services | Атрибуты сферы услуг | [TicketRequest::Domain](Сфера%20деятельности%20чека.md)::Services | Обазательно только если type == [DOMAIN_SERVICES \| DOMAIN_HOTELS], игнорируется в остальных случаях |  |
| gasoil | Атрибуты сферы обеспечения нефтепродуктами | [TicketRequest::Domain](Сфера%20деятельности%20чека.md)::GasOil | Обазательно только при type == DOMAIN_GASOIL, игнорируется в остальных случаях |  |
| taxi | Атрибуты такси | [TicketRequest::Domain](Сфера%20деятельности%20чека.md)::Taxi | Обазательно при type == DOMAIN_TAXI, игнорируется в остальных случаях |  |
| parking | Атрибуты стоянок | [TicketRequest::Domain](Сфера%20деятельности%20чека.md)::Parking | Обазательно при type == DOMAIN_PARKING, игнорируется в остальных случаях |  |

> [!NOTE]
> См. подробное описание структуры в файле [TicketRequest::Domain](Сфера%20деятельности%20чека.md).

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message Domain {
    message Services {
      required string account_number = 1;
    }

    message GasOil {
      optional string correction_number = 1;
      optional Money correction_sum = 2;
      optional string card_number = 3;
    }

    message Taxi {
      required string car_number = 1;
      required bool is_order = 2;
      required Money current_fee = 3;
    }

    message Parking {
      required DateTime begin_time = 1;
      required DateTime end_time = 2;
    }

    required DomainTypeEnum type = 1;
    optional Services services = 2;
    optional GasOil gasoil = 3;
    optional Taxi taxi = 4;
    optional Parking parking  = 5;
  }
```
