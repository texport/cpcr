# Итоги по чеку (TicketRequest::Amounts)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| total | Общая сумма чека | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| taken | Полученная сумма | [Money](../../../Общие%20типы%20данных/Деньги.md) | нет* | (*) Обязательно при наличной оплате |
| change | Сумма сдачи | [Money](../../../Общие%20типы%20данных/Деньги.md) | нет* | (*) Обязательно при наличной оплате |
| markup | Общая сумма наценки | [TicketRequest::Modifier](Модификатор%20стоимости.md) | нет* | (*) Это поле должно отсутствовать, если указана сумма скидок |
| discount | Общая сумма скидки | [TicketRequest::Modifier](Модификатор%20стоимости.md) | нет* | (*) Это поле должно отсутствовать, если указана сумма наценок |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message Amounts {
    required Money total = 1;
    optional Money taken = 2;
    optional Money change = 3;
    optional Modifier markup = 4;
    optional Modifier discount = 5;
  }
```
