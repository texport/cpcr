# Реквизиты оплаты картой (TicketRequest::Payment::CardPaymentFields)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| pos_terminal_id | Уникальный идентификатор терминала | String | нет |  |
| pos_card_type | Тип карты | String | нет |  |
| pos_autorization_code | Код авторизации | Uint32 | нет |  |
| pos_rrn | Уникальное значения номера операции (Reference<br>Number) | uint64 | нет |  |
| pos_receipt_number | Номер чека в системе банка | uint64 | нет |  |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message CardPaymentFields {
      optional string pos_terminal_id = 1;
      optional string pos_card_type = 2;
      optional uint32 pos_autorization_code = 3;
      optional uint64 pos_rrn = 4; // до версии 203 тип uint32
      optional uint64 pos_receipt_number = 5;
    }
```
