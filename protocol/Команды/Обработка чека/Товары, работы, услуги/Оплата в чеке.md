# Оплата в чеке (TicketRequest::Payment)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Вид оплаты | [PaymentTypeEnum](../../../Общие%20типы%20данных/Типы%20оплат.md) | да |  |
| sum | Уплаченная сумма | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| card_payment_fields | Реквизиты оплаты картой | [CardPaymentFields](Реквизиты%20оплаты%20картой.md) | нет |  |
| mobile_payment_fields | Реквизиты мобильного платежа | [MobilePaymentFields](Реквизиты%20мобильного%20платежа.md) | нет |  |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message Payment {
    message CardPaymentFields {
      optional string pos_terminal_id = 1;
      optional string pos_card_type = 2;
      optional uint32 pos_autorization_code = 3;
      optional uint64 pos_rrn = 4; // до версии 203 тип uint32
      optional uint32 pos_receipt_number = 5;
    }

    message MobilePaymentFields {
      optional string qr_type = 1;
      optional string qr_id = 2;
    }

    required PaymentTypeEnum type = 1;
    required Money sum = 2;
    optional CardPaymentFields card_payment_fields = 3; // добавлено в версии 203
    optional MobilePaymentFields mobile_payment_fields = 4; // добавлено в версии 203
  }
```
