# Налог в чеке (TicketRequest::Tax)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Тип налога | [TaxTypeEnum](../../../Общие%20типы%20данных/Типы%20налогов.md) | да |  |
| taxation_type | Вид налогообложения | [TaxationTypeEnum](../../../Общие%20типы%20данных/Виды%20налогообложений.md) | нет |  |
| percent | Значение налога в процентах | uint32 | да | В тысячных долях процента, например 12000 == 12,0% |
| sum | Значение налога в деньгах | [Money](../../../Общие%20типы%20данных/Деньги.md) | да |  |
| is_in_total_sum | Заложен ли налог в сумму | bool | да | Признак того, включена ли сумма налога в сумму товара, работы, услуги |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message Tax {
    required TaxTypeEnum type = 1;
    optional TaxationTypeEnum taxation_type = 2; // optional с версии 200
    required uint32 percent = 3;
    required Money sum = 4;
    required bool is_in_total_sum = 5;
  }
```
