# Родительский чек возврата (TicketRequest::ParentTicket)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| parent_ticket_number | Фискальный признак чека основания для возврата | String | да* | Поля содержат<br>данные чека продажи или покупки, на основании которого оформляется<br>возврат.  (*) Обязательно при [OperationTypeEnum](../../../Общие%20типы%20данных/Операции%20с%20чеком.md) == OPERATION_BUY_RETURN или [OperationTypeEnum](../../../Общие%20типы%20данных/Операции%20с%20чеком.md) == OPERATION_SELL_RETURN |
| parent_ticket_data_time | Дата и время операции родительского чека (чека основаия) | [DateTime](../../../Общие%20типы%20данных/Дата%20и%20время.md) | да* |  |
| kgd_kkm_id | Регистрационный номер ККМ  КГД чека основания для возврата | string | да* |  |
| parent_ticket_total | Общая сумма покупки или продажи чека основания для возврата | [Money](../../../Общие%20типы%20данных/Деньги.md) | да* |  |
| parent_ticket_is_offline | Флаг того, что чека основания для возврата был автономным. | bool | да* |  |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message ParentTicket {
    required string parent_ticket_number = 1;
    required DateTime parent_ticket_data_time = 2;
    required string kgd_kkm_id = 3;
    required Money parent_ticket_total = 4;
    required bool parent_ticket_is_offline = 5;
  }
```
