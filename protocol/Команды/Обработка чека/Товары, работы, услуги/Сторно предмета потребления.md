# Сторно предмета потребления (TicketRequest::Item::StornoCommodity)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| name | Наименование операции сторно | string | нет |  |
| section_code | Код секции или отдела | string | да | Сюда также входят:<br>- номер раздаточного крана для бензоколонок;<br>- тип услуги или подразделения для отелей и ресторанов. |
| quantity | Количество товара, работы,  услуги | uint64 | да | В тысячных долях, например 1000 == 1,0, 2500 == 2,5<br>Сюда также входит оплаченный пробег для такси |
| price | Цена товара, работы, услуги | [Money](../../../Общие%20типы%20данных/Деньги.md) | да | Стоимость единицы товара, работы, услуги |
| sum | Итоговая сумма товара, работы, услуги | [Money](../../../Общие%20типы%20данных/Деньги.md) | да | Итоговая сумма товара или услуги с учетом количества и исчисляемых налогов |
| taxes | Список налогов | List<[TicketRequest::Tax](Налог%20в%20чеке.md)> | 0…n | Налоги на позиции и налог на весь чек являются взаимоисключающими. При формировании чека нельзя указывать налоги в обеих секциях.<br>Налог с определённым процентом должен встречаться не более одного раза. |
| list_excise_stamp | Список кодов | List<string> | нет | Поле содержит список кодов DataMatrix из информационной системы маркировки и прослеживаемости товаров при его наличии для товаров имеющих одинаковый штрихкод (gtin/ntin). |
| physical_label | Серия и номер акцизной марки | string | нет | Поле содержит серию и номер акцизной марки при её наличии. |
| product_id | Сквозной идентификатор товара | uint64 | нет | (*) Обязательно для товаров модуля Виртуальный склад ИС ЭСФ, если не задано поле barcode. |
| barcode | Штрих-код | string | нет | Поле содержит штрих-код GTIN при его наличии. (*) Обязательно для товаров модуля Виртуальный склад ИС ЭСФ, если не задано поле product_id. |
| ntin | Штрих-код | string | нет | Поле содержит штрих-код Ntin при его наличии. (*) Обязательно для товаров модуля Виртуальный склад ИС ЭСФ, если не задано поле product_id. |
| measure_unit_code | Код единицы измерения | string | да | Код единицы измерения в ИС ЭСФ |
| commodity_type | Тип элемента списка | [CommodityTypeEnum](Тип%20элемента%20списка.md) | да, для товаров с NTIN | К какому типу (товару, работе или услуге) относится элемент списка |
| auxiliary | Дополнительная информация | [KeyValuePair](../../../Общие%20типы%20данных/Дополнительная%20информация%20в%20формате%20key,%20value.md) | 0…n |  |

### Спецификация на уровне Protobuf

Имя файла: [ticket.proto](../../../../proto/ticket.proto)

```protobuf
message StornoCommodity {
      reserved 7;
      reserved "excise_stamp";

      optional string name = 1;
      required string section_code = 2;
      required uint64 quantity = 3; // до версии 203 тип uint32
      required Money price = 4;
      required Money sum = 5;
      repeated Tax taxes = 6;
      repeated KeyValuePair auxiliary = 8; // добавлено в версии 200
      optional string physical_label = 9; // добавлено в версии 200
      optional string product_id = 10; // добавлено в версии 200
      optional string barcode = 11; // добавлено в версии 200
      required string measure_unit_code = 12; // добавлено в версии 201
      repeated string list_excise_stamp = 13; // добавлено в версии 203
      optional string ntin = 14; // добавлено в версии 203
      optional CommodityTypeEnum commodity_type = 15;
    }
```
