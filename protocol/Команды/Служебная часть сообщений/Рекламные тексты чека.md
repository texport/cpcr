# Рекламные тексты чека

В чеках могут содержаться текстовые блоки рекламного или информационного характера. Значения этих текстовых блоков синхронизируются в соответствующих полях служебного пакета. ККМ может добавлять в запрос информацию о версиях текстов, которые у него имеются, а сервер, при необходимости, возвращает новые версии.

Отправка на сервер

ККМ заполняет поле ServiceRequest::ticket_ad_infos своими значениями.

Ответ сервера

# Рекламный текстовый блок (TicketAd)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| info | Информация о текстовом блоке | [TicketAdInfo](../../Общие%20типы%20данных/Информация%20о%20рекламных%20текстах%20для%20чека.md) | да |  |
| text | Текст | string | да |  |

> [!NOTE]
> См. подробное описание структуры в файле [TicketAd](Рекламные%20тексты%20чека.md).

### Спецификация на уровне Protobuf

Имя файла: [adinfo.proto](../../../proto/adinfo.proto)

```protobuf
message TicketAd {
  required TicketAdInfo info = 1;
  required string text = 2;
}
```
