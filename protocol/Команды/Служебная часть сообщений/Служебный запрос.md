# Служебный запрос (ServiceRequest)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| comm_quality | Качество связи | [ServiceRequest:CommQuality](Качество%20соединения.md) | нет |  |
| software_information | Информация о среде исполнения | [ServiceRequest::SoftwareInformation](Информация%20о%20среде%20исполнения.md) | нет |  |
| security_stats | Безопасность и статистика | [ServiceRequest::SecurityStats](Безопасность%20и%20статистика.md) | нет* | Обязательно для команд;<br>[COMMAND_TICKET](../Обработка%20чека/Обработка%20чека.md)<br>[COMMAND_CLOSE_SHIFT](../Закрытие%20смены/Закрытие%20смены.md)<br>[COMMAND_REPORT](../Отправка%20и%20получение%20отчетов/Отправка%20и%20получение%20отчетов.md)<br>[COMMAND_MONEY_PLACEMENT](../Внесение%20и%20снятие%20денег/Внесение%20и%20снятие%20денег.md) |
| offline_period | Автономный режим | [ServiceRequest::OfflinePeriod](Период%20автономной%20работы%20в%20запросе.md) | нет* | Время перехода в автономный режим и возврата в нормальный режим |
| nomenclature_version | Версия номенклатуры | uint32 | нет | Текущая версия номенклатуры, загруженной в кассу |
| ticket_ad_infos | Информация о рекламных текстах | List<[TicketAdInfo](../../Общие%20типы%20данных/Информация%20о%20рекламных%20текстах%20для%20чека.md)> | 0…n | Версии и типы рекламных текстов, загруженных на ККМ<br>n==[TicketAdTypeEnum](../../Общие%20типы%20данных/Типы%20рекламных%20текстов%20для%20чека.md)::size |
| get_reg_info | Признак получения регистрационной информации | bool | нет | С помощью этого флага ККМ может запросить информацию об организации, кассе и/или торговой точке |
| get_binded_taxation | Признак получения привязанного налогообложения | bool | нет | Устройство может получить привязанное налогообложение, выставив это флаг в true |
| auxiliary | Дополнительная информация | [KeyValuePair](../../Общие%20типы%20данных/Дополнительная%20информация%20в%20формате%20key,%20value.md) | 0…n |  |
| reg_info | Регистрационные данные | [ServiceRequest::RegInfo](Регистрационные%20данные%20запроса.md) | да | Устройство должно отправлять  эти данные в каждом фискальном запросе |

### Спецификация на уровне Protobuf

Имя файла: [service.proto](../../../proto/service.proto)

```protobuf
message ServiceRequest {
  message CommQuality {
    required uint32 avg_connect_time = 1;
    optional uint32 avg_ping = 2;
    optional uint32 loss_ratio = 3;
  }

  message OfflinePeriod {
    required DateTime begin_time = 1;
    required DateTime end_time = 2;
  }

  message SoftwareInformation {
    message ModuleInformation {
      message DeviceInformation {
        optional string manufacturer = 1;
        optional string model = 2;
        optional string firmware_version = 3;
      }

      required string name = 1;
      required string version = 2;
      optional string build_info = 3;
      optional DeviceInformation device_info = 4;
      repeated KeyValuePair extended_info = 5;
      optional string build_arch = 6;
    }

    repeated ModuleInformation module_infos = 1;
    optional string hardware_arch = 2;
    optional string os_family = 3;
    optional string os_version = 4;
    optional string os_extended_info = 5;
    optional string runtime_version = 6;
    optional uint32 partner_id = 7;
  }

  message RegInfo {
    required KkmRegInfo kkm = 1; // required с версии 200
    required OrgRegInfo org = 2; // required с версии 200
  }

  message SecurityStats {
    message GeoPosition {
      required uint32 latitude = 1;
      required uint32 longitude = 2;
      required string source = 3;
    }

    required GeoPosition geo_position = 1; // добавлено в версии 203
  }

  optional CommQuality comm_quality = 1;
  optional SecurityStats security_stats = 3; // required для COMMAND_TICKET, COMMAND_CLOSE_SHIFT, COMMAND_REPORT и COMMAND_MONEY_PLACEMENT
  optional OfflinePeriod offline_period = 4;
  optional uint32 nomenclature_version = 5;
  repeated TicketAdInfo ticket_ad_infos = 6;
  optional bool get_reg_info  = 7;
  optional bool get_binded_taxation = 8;
  optional SoftwareInformation software_information = 11;
  required RegInfo reg_info = 12; // required с версии 200
  repeated KeyValuePair auxiliary = 60;
}
```
