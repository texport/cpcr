# Информация о модуле ПО (ServiceRequest::SoftwareInformation::ModuleInformation)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| name | Название модуля | uint32 | да |  |
| version | Версия модуля | uint32 | да |  |
| build_info | Информация о сборке | uint32 | нет |  |
| device_info | Информация об устройстве | [ServiceRequest::SoftwareInformation::ModuleInformation](Информация%20о%20модуле%20ПО.md)::<br>[DeviceInformation](Информация%20об%20устройстве.md) | нет |  |
| extended_info | Дополнительная информация | [KeyValuePair](../../Общие%20типы%20данных/Дополнительная%20информация%20в%20формате%20key,%20value.md) | 0…n |  |
| build_arch | Архитектура сборки | string | нет |  |

### Спецификация на уровне Protobuf

Имя файла: [service.proto](../../../proto/service.proto)

```protobuf
message ModuleInformation {
      message DeviceInformation {
        optional string manufacturer = 1;
        optional string model = 2;
        optional string firmware_version = 3;
      }

      required string name = 1;
      required string version = 2;
      optional string build_info = 3;
      optional DeviceInformation device_info = 4;
      repeated KeyValuePair extended_info = 5;
      optional string build_arch = 6;
    }
```
