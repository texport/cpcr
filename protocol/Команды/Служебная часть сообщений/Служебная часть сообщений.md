# Служебная часть сообщений

Служебная часть предназначена для контроля состояния ККМ и его обслуживания. Возможна передача системных пакетов при каждом обращении к серверу. Задачи:

мониторинг состояния ККМ (онлайн и офлайн);

получение служебной информации

получение рекламных текстов

| Код команды | [COMMAND_SYSTEM](../Служебный%20обмен/Служебный%20обмен.md) если команда идет в отдельном запросе, иначе код основной команды запроса. |
