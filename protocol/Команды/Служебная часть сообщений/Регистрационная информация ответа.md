# Регистрационная информация ответа (ServiceResponse::RegInfo)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| kkm | Информация о ККМ | [KkmRegInfo](../../Общие%20типы%20данных/Регистрационные%20данные%20ККМ.md) | да |  |
| pos | Информация о торговой точке | [PosRegInfo](../../Общие%20типы%20данных/Регистрационные%20данные%20торговой%20точки.md) | нет |  |
| org | Информация об организации | [OrgRegInfo](../../Общие%20типы%20данных/Регистрационные%20данные%20организации.md) | да |  |

### Спецификация на уровне Protobuf

Имя файла: [service.proto](../../../proto/service.proto)

```protobuf
message RegInfo {
    required KkmRegInfo kkm = 1; // required с версии 200
    optional PosRegInfo pos = 2;
    required OrgRegInfo org = 3; // required с версии 200
  }
```
