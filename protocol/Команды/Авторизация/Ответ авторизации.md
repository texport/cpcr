# Ответ авторизации (AuthResponse)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| result | Результат авторизации | [AuthResponse::ResultTypeEnum](Код%20результата%20авторизации.md) | да |  |
| operator_code | Код оператора-кассира | uint32 | нет* | (*)Обязательно при result == RESULT_TYPE_OK |
| operator_name | Наименование  оператора-кассира | string | нет* | (*)Обязательно при result == RESULT_TYPE_OK |
| roles | Роли пользователя | List<[UserRoleEnum](../../Общие%20типы%20данных/Роли%20пользователей.md)> | 0…n | Список ролей, назначенных пользователю<br>n==[UserRoleEnum](../../Общие%20типы%20данных/Роли%20пользователей.md)::size |

### Спецификация на уровне Protobuf

Имя файла: [auth.proto](../../../proto/auth.proto)

```protobuf
message AuthResponse {
  enum ResultTypeEnum {
    RESULT_TYPE_OK = 0;
    RESULT_TYPE_INVALID_LOGIN_PASSWORD = 1;
  }
  
  required ResultTypeEnum result = 1;
  optional uint32 operator_code = 2;
  optional string operator_name = 3;
  repeated UserRoleEnum roles = 4;
}
```
