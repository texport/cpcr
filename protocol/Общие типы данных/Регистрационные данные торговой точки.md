# Регистрационные данные торговой точки (PosRegInfo)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| title | Название торговой точки | string | да |  |
| address | Адрес  торговой точки | string | да |  |
| address_kz | Адрес  торговой точки на гос языке | string | да |  |
| latitude | Широта | uint32 | да | в 10000 долях |
| longitude | Долгота | uint32 | да | в 10000 долях |

### Спецификация на уровне Protobuf

Имя файла: [reginfo.proto](../../proto/reginfo.proto)

```protobuf
message PosRegInfo {
  required string title = 1; // required с версии 200
  required string address = 2; // required с версии 200
  required string address_kz = 3; // добавлен в версии 203
  required uint32 latitude = 4; // добавлен в версии 203
  required uint32 longitude = 5; // добавлен в версии 203
}
```
