# Сведения об операторе-кассире

**Оператор-кассир (Operator)**

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| code | Код оператора-кассира | uint32 | да | Сюда также входят:<br>- номер оператора для бензоколонок;<br>- шифр официанта или портье для отелей и ресторанов<br>- идентификатор водителя для такси. |
| name | ФИО оператора-кассира | string | нет |  |

### Спецификация на уровне Protobuf

Имя файла: [common.proto](../../proto/common.proto)

```protobuf
message Operator {
  required uint32 code = 1;
  optional string name = 2;
}
```
