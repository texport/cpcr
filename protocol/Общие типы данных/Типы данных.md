# Типы данных

В данном разделе описаны общие типы данных и перечисления (Enums), используемые в различных сообщениях и командах протокола обмена.

### Список общих типов данных:

* **Базовые типы**:
  * [Дата (Date)](Дата.md) — структура для передачи календарной даты.
  * [Время (Time)](Время.md) — структура для передачи времени.
  * [Дата и время (DateTime)](Дата%20и%20время.md) — комбинированная структура даты и времени.
  * [Деньги (Money)](Деньги.md) — структура для передачи денежных сумм (в тиынах).

* **Перечисления (Enums)**:
  * [Вид отрасли (DomainTypeEnum)](Вид%20отрасли.md) — сферы деятельности торговой точки.
  * [Операции с чеком (OperationTypeEnum)](Операции%20с%20чеком.md) — типы фискальных операций.
  * [Типы оплат (PaymentTypeEnum)](Типы%20оплат.md) — способы оплаты (наличные, карта, мобильный платеж).
  * [Режимы налогообложения (TaxationTypeEnum)](Виды%20налогообложений.md) — применяемые режимы налогообложения.
  * [Типы налогов (TaxTypeEnum)](Типы%20налогов.md) — виды налогов (НДС и др.).
  * [Роли пользователей (UserRoleEnum)](Роли%20пользователей.md) — права и роли пользователей.
  * [Типы рекламных текстов (TicketAdTypeEnum)](Типы%20рекламных%20текстов%20для%20чека.md) — категории рекламных блоков.

* **Вспомогательные структуры**:
  * [Пара ключ-значение (KeyValuePair)](Дополнительная%20информация%20в%20формате%20key,%20value.md) — передача произвольных дополнительных параметров.
  * [Сведения об операторе (Operator)](Сведения%20об%20операторе-кассире.md) — данные кассира.
  * [Информация о рекламе (TicketAdInfo)](Информация%20о%20рекламных%20текстах%20для%20чека.md) — метаданные рекламных текстов.

* **Регистрационные данные**:
  * [Регистрационные данные ККМ (KkmRegInfo)](Регистрационные%20данные%20ККМ.md)
  * [Регистрационные данные торговой точки (PosRegInfo)](Регистрационные%20данные%20торговой%20точки.md)
  * [Регистрационные данные организации (OrgRegInfo)](Регистрационные%20данные%20организации.md)

* **Связанное налогообложение**:
  * [Связанное налогообложение (BindedTaxation)](Связанное%20налогообложение/Связанное%20налогообложение.md)
  * [Связанная ставка налога (BindedTaxation::BindedTax)](Связанное%20налогообложение/Связанная%20ставка%20налога.md)
