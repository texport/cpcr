# Время

**Time**

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| hour | Час | uint32 | да | Диапазон 0-23 |
| minute | Минута | uint32 | да | Диапазон 0-59 |
| second | Секунда | uint32 | нет | Диапазон 0-59 |

### Спецификация на уровне Protobuf

Имя файла: [common.proto](../../proto/common.proto)

```protobuf
message Time {
  required uint32 hour = 1; // число от 0 до 23
  required uint32 minute = 2; // число от 0 до 59
  optional uint32 second = 3; // число от 0 до 59
}
```
