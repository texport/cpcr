# Регистрационные данные организации (OrgRegInfo)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| title | Название организации или ФИО индивидуального предпринимателя | string | да |  |
| address | Юридический адрес  организации | string | да |  |
| address_kz | Юридический адрес  организации на гос языке | string | да |  |
| iin | ИИН/БИН | string | да |  |
| oked | Общий классификатор экономической деятельности (далее - ОКЭД) | string | да |  |

### Спецификация на уровне Protobuf

Имя файла: [reginfo.proto](../../proto/reginfo.proto)

```protobuf
message OrgRegInfo {
  required string title = 1; // required с версии 200
  required string address = 2; // required с версии 200
  required string iin = 3; // required с версии 200
  required string oked = 5; // required с версии 200
  required string address_kz = 6; // добавлен в версии 203
}
```
