# Регистрационные данные ОФД (OfdRegInfo)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| title | Наименование ОФД на русском языке | string | да | Наименование ОФД (рус.) |
| title_kz | Наименование ОФД на казахском языке | string | да | Наименование ОФД (каз.) |
| url | Ссылка на сайт ОФД | string | да | URL-адрес официального сайта ОФД |

### Спецификация на уровне Protobuf

Имя файла: [reginfo.proto](../../proto/reginfo.proto)

```protobuf
message OfdRegInfo {
  required string title = 1; // добавлен с версии 204
  required string title_kz = 2; // добавлен с версии 204
  required string url = 3; // добавлен с версии 204
}
```
