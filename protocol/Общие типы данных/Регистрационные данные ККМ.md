# Регистрационные данные ККМ (KkmRegInfo)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| point_of_payment_number | Регистрационный номер (код) точки приема платежей | string | нет |  |
| terminal_number | Номер платежного терминала | string | нет |  |
| fns_kkm_id | Регистрационный номер ККМ, выданный КГД | string | да, для close shift / report |  |
| serial_number | Заводской номер ККМ | string |  |  |
| kkm_id | Идентификационный номер ККМ | string |  |  |

### Спецификация на уровне Protobuf

Имя файла: [reginfo.proto](../../proto/reginfo.proto)

```protobuf
message KkmRegInfo {
  optional string point_of_payment_number = 1;
  optional string terminal_number = 2;
  optional string fns_kkm_id = 3; // required с версии 125 при command == COMMAND_CLOSE_SHIFT || command == COMMAND_REPORT
  optional string serial_number = 4; // required с версии 125 при command == COMMAND_CLOSE_SHIFT || command == COMMAND_REPORT
  optional string kkm_id =5; // required с версии 125 при command == COMMAND_CLOSE_SHIFT || command == COMMAND_REPORT
}
```
