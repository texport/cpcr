# Связанное налогообложение (BindedTaxation)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Тип налогообложения | [TaxationTypeEnum](../Виды%20налогообложений.md) | да |  |
| taxes | Ставки для каждого налога | List<[BindedTax](Связанная%20ставка%20налога.md)> | 0..n | Не более одной структуры для каждого налога |

### Спецификация на уровне Protobuf

Имя файла: [taxation.proto](../../../proto/taxation.proto)

```protobuf
message BindedTaxation {
  message BindedTax {
    required TaxTypeEnum type  = 1;
    required uint32 percent = 2;
  }

  required TaxationTypeEnum type  = 1;
  repeated BindedTax taxes = 2;
}
```
