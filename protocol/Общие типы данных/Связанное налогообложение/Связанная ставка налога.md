# Связанная ставка налога (BindedTaxation::BindedTax)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| type | Тип налога | [TaxTypeEnum](../Типы%20налогов.md) | да |  |
| percent | Значение налога в процентах | uint32 | да | В тысячных долях процента, например 1500 == 1,5% |

### Спецификация на уровне Protobuf

Имя файла: [taxation.proto](../../../proto/taxation.proto)

```protobuf
message BindedTax {
    required TaxTypeEnum type  = 1;
    required uint32 percent = 2;
  }
```
