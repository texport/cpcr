# Работа в режиме блокировки

> [!CAUTION]
> **РЕЖИМ БЛОКИРОВКИ (BLOCKED)**
> В этот режим устройство переходит, если какое-либо из офлайн-сообщений при передаче на сервер вызывает устойчивую ошибку.
> В этом режиме **никакая работа устройства не разрешена** до тех пор, пока проблемное сообщение не будет удалено из очереди после анализа специалистом службы поддержки.
