# Работа в режиме серверной блокировки

> [!WARNING]
> **СЕРВЕРНАЯ БЛОКИРОВКА**
> В этот режим устройство должно переходить, если от сервера приходит ответ `RESULT_TYPE_BLOCKED` (код `15`).
> Устройство должно напечатать и/или вывести на экран ранее полученное информационное сообщение — `ServiceResponse.ticket_ads` (тип `TICKET_AD_INFO`).
> В этом режиме работа кассы приостанавливается. Устройство должно периодически отправлять на сервер запрос `COMMAND_SYSTEM` с заполненным регистрационными данными (`service.reg_info`). Выход из блокировки происходит автоматически после получения от сервера ответа с кодом `RESULT_TYPE_OK` (код `0`).

### Работа после выхода из блокировки

Устройство после выхода из блокировки должно проверить все записи, не переданные на сервер ОФД, после успешной проверки отправить на сервер ОФД сообщение с количеством о непереданных записях

Отправить записи в последовательности, накопленные во время работы в автономном режиме, получая на каждый из них ответ от сервера с кодом RESULT_TYPE_OK

Сервер ОФД, после приема всех записей, отправляет ответ устройству сообщение об успешном приеме сообщений.
