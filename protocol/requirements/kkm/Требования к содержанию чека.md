# Глава 3. Перечень требований к содержанию чека контрольно-кассовой машины

Данный раздел содержит государственные технические требования к содержанию чека контрольно-кассовой машины (ККМ) в Республике Казахстан согласно Главе 3 Приказа Министра финансов РК № 626.

| № п/п | Требования к содержанию чека | Сведения о соответствии | Примечание |
| :--- | :--- | :--- | :--- |
| **55** | **При применении контрольно-кассовой машины осуществляется выдача чека контрольно-кассовой машины или товарного чека на сумму, оплаченную за реализованный товар, выполненную работу, оказанную услугу.** | | Перечень требований к содержанию чека ККМ устанавливается уполномоченным органом. |
| **56** | **Чек контрольно-кассовой машины включает следующую информацию:** | | |
| 56.1 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 1) наименование налогоплательщика; | | |
| 56.2 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 2) адрес места использования контрольно-кассовой машины; | | |
| 56.3 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 3) идентификационный номер налогоплательщика; | | |
| 56.4 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 4) заводской номер контрольно-кассовой машины; | | |
| 56.5 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 5) регистрационный номер контрольно-кассовой машины в налоговом органе; | | |
| 56.6 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 6) порядковый номер чека; | | |
| 56.7 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 7) наименование товара, работы, услуги в соответствии с национальным каталогом товаров; | | В чеке ККМ с функцией фиксации и (или) передачи данных отображается в электронном виде. |
| 56.8 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 8) идентификационный код товара в соответствии с национальным каталогом и средство идентификации нанесенных на товары, подлежащих маркировке и прослеживаемости товаров; | | |
| 56.9 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 9) количество приобретаемого товара, работ, услуг, единицу их измерения; | | |
| 56.10 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 10) цену товара, работы, услуги за единицу; | | |
| 56.11 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 11) общую сумму продажи товара, работы, услуги; | | |
| 56.12 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 12) наименование оператора фискальных данных и реквизиты интернет-ресурса оператора фискальных данных для проверки подлинности контрольного чека контрольно-кассовых машин с функцией фиксации и (или) передачи данных; | | Не распространяется на чеки ККМ без функции передачи данных. |
| 56.13 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 13) дату и время совершения покупки товаров, выполнения работ, оказания услуг; | | |
| 56.14 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 14) фискальный признак; | | |
| 56.15 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 15) сумму налога на добавленную стоимость с указанием ставки по облагаемым налогом на добавленную стоимость оборотам по реализации товаров, работ, услуг – в случае, если налогоплательщик является плательщиком налога на добавленную стоимость; | | |
| 56.16 | &nbsp;&nbsp;&nbsp;&nbsp;↳ 16) штриховой код, содержащий в кодированном виде информацию о чеке контрольно-кассовой машины; | | Не распространяется на чеки ККМ без функции передачи данных. |
| 56.17 | &nbsp;&nbsp;&nbsp;&nbsp;↳ Чек контрольно-кассовых машин, применяемых в пунктах обмена валюты, приема лома металлов, стеклопосуды, ломбардов, дополнительно включает информацию о сумме продаж и сумме покупки. | | |
| **57** | **Чек контрольно-кассовой машины дополнительно содержит реквизиты, предусмотренные технической документацией завода-изготовителя контрольно-кассовой машины, в том числе о сумме налога на добавленную стоимость.** | | |
| 57.1 | &nbsp;&nbsp;&nbsp;&nbsp;↳ По требованию покупателя (клиента), получателя товаров, работ, услуг в чеке контрольно-кассовой машины с функцией фиксации и (или) передачи данных отображается идентификационный номер покупателя (клиента), получателя; | | |
| 57.2 | &nbsp;&nbsp;&nbsp;&nbsp;↳ Вся информация, содержащаяся в чеке контрольно-кассовой машины по требованию покупателя (клиента), получателя товаров, работ, услуг отражается и печатается на казахском и (или) русском языках. | | |
