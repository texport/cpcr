# Статус ответа сервера (Result)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| result_code | Код ответа | uint32 | да | Тип uint32 позволяет использовать весь диапазон значений этого типа, что дает возможность не ломать бинарную совместимость при расширении набора кодов ответов. Однако для каждой конкретной версии протокола данное поле должно иметь значения из диапазона, задаваемого типом [ResultTypeEnum](Коды%20ответов.md). |
| result_text | Строка ответа | string | нет | Строка с текстом системного характера для обработки ошибок |

### Спецификация на уровне Protobuf

Имя файла: [message.proto](../../proto/message.proto)

```protobuf
message Result {
  required uint32 result_code = 1; // число из диапазона ResultTypeEnum
  optional string result_text = 2;
}
```
