# Структура запроса к серверу (Request)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| command | Код команды | [CommandTypeEnum](Коды%20команд.md) | да | см. [CommandTypeEnum](Коды%20команд.md) данного документа |
| ticket<br> | Чековая транзакция | [TicketRequest](../Команды/Обработка%20чека/Запрос%20чека.md) | да, если command = [COMMAND_TICKET](../Команды/Обработка%20чека/Обработка%20чека.md)<br>игнорируется в остальных случаях |  |
| close_shift | Закрытие смены | [CloseShiftRequest](../Команды/Закрытие%20смены/Запрос%20закрытия%20смены.md) | да, если command = [COMMAND_CLOSE_SHIFT](../Команды/Закрытие%20смены/Закрытие%20смены.md)<br>игнорируется в остальных случаях |  |
| report<br> | Запрос отчета | [ReportRequest](../Команды/Отправка%20и%20получение%20отчетов/Запрос%20отчета.md) | да, если command = [COMMAND_REPORT](../Команды/Отправка%20и%20получение%20отчетов/Отправка%20и%20получение%20отчетов.md)<br>игнорируется в остальных случаях |  |
| nomenclature | Синхронизация номенклатуры | [NomenclatureRequest](../Команды/Получение%20номенклатуры/Запрос%20номенклатуры.md) | да, если command = [COMMAND_NOMENCLATURE](../Команды/Получение%20номенклатуры/Получение%20номенклатуры.md)<br>игнорируется в остальных случаях |  |
| service | Системная часть | [ServiceRequest](../Команды/Служебная%20часть%20сообщений/Служебный%20запрос.md) | обязательно для протокола 2.0.3 | см. [ServiceRequest_Response](../Команды/Служебная%20часть%20сообщений/Служебная%20часть%20сообщений.md) |
| money_placement | Снятие/внесение наличных | [MoneyPlacementRequest](../Команды/Внесение%20и%20снятие%20денег/Запрос%20внесения-снятия%20денег.md) | да, если command = [COMMAND_MONEY_PLACEMENT](../Команды/Внесение%20и%20снятие%20денег/Внесение%20и%20снятие%20денег.md)<br>игнорируется в остальных случаях |  |
| auth | Авторизация | [AuthRequest](../Команды/Авторизация/Запрос%20авторизации.md) | да, если command = [COMMAND_AUTH](../Команды/Авторизация/Авторизация.md)<br>игнорируется в остальных случаях |  |
|  |  |  |  |  |

> [!NOTE]
> См. подробное описание структуры в файле [Request](Структура%20запроса%20к%20серверу.md).

### Спецификация на уровне Protobuf

Имя файла: [message.proto](../../proto/message.proto)

```protobuf
message Request {
  required CommandTypeEnum command = 1;
  optional TicketRequest ticket = 2; // required при command == COMMAND_TICKET
  optional CloseShiftRequest close_shift = 3; // required при command == COMMAND_CLOSE_SHIFT
  optional ReportRequest report = 4; // required при command == COMMAND_REPORT
  optional NomenclatureRequest nomenclature = 5; // required при command == COMMAND_NOMENCLATURE
  optional ServiceRequest service = 6; // required с версии 125 при command == COMMAND_CLOSE_SHIFT || command == COMMAND_REPORT
  optional MoneyPlacementRequest money_placement = 7; // required при command == COMMAND_MONEY_PLACEMENT
  optional AuthRequest auth = 8; // required при command == COMMAND_AUTH
}
```
