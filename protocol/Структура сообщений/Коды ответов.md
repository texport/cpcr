# Коды ответов

Сервер отвечает всегда с тем же кодом команды, с которым устройство обратилось к нему. Дополнительно сервер отсылает специальную структуру данных, содержащую код ответа и данные, специфичные для данного кода, если они необходимы. Список кодов ответа общего характера перечислен в данном разделе. Специфические коды ответов для конкретных команд описаны в соответствующих разделах.

### Спецификация на уровне Protobuf

Имя файла: [message.proto](../../proto/message.proto)

```protobuf
enum ResultTypeEnum {
  reserved 16, 10; // Исключённые коды команд
  reserved "RESULT_TYPE_CURRENT_SHIFT_WAS_OPENED", "RESULT_TYPE_CANT_CANCEL_TICKET"; // Название исключённых команд
  
  RESULT_TYPE_OK = 0;
  RESULT_TYPE_UNKNOWN_ID = 1;
  RESULT_TYPE_INVALID_TOKEN = 2;
  RESULT_TYPE_PROTOCOL_ERROR = 3;
  RESULT_TYPE_UNKNOWN_COMMAND = 4;
  RESULT_TYPE_UNSUPPORTED_COMMAND = 5;
  RESULT_TYPE_INVALID_CONFIGURATION = 6;
  RESULT_TYPE_SSL_IS_NOT_ALLOWED = 7; // не используется
  RESULT_TYPE_INVALID_REQUEST_NUMBER = 8;
  RESULT_TYPE_INVALID_RETRY_REQUEST = 9;
  RESULT_TYPE_OPEN_SHIFT_TIMEOUT_EXPIRED = 11;
  RESULT_TYPE_INVALID_LOGIN_PASSWORD = 12; // не используется
  RESULT_TYPE_INCORRECT_REQUEST_DATA = 13;
  RESULT_TYPE_NOT_ENOUGH_CASH = 14;
  RESULT_TYPE_BLOCKED = 15;
  RESULT_TYPE_SAME_TAXPAYER_AND_CUSTOMER = 17; // добавлено в версии 202
  RESULT_TYPE_DEREGISTERED = 18;
  RESULT_TYPE_DISCONNECTED = 19;
  RESULT_TYPE_SERVICE_TEMPORARILY_UNAVAILABLE = 254;
  RESULT_TYPE_UNKNOWN_ERROR = 255;
}
```
