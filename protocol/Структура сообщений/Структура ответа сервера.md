# Структура ответа сервера (Response)

| Поле | Наименование | Тип данных | Обязательно | Примечания |
| --- | --- | --- | --- | --- |
| command | Код команды | [CommandTypeEnum](Коды%20команд.md) | да | Тот же код, который был в запросе |
| result | Статус ответа | [Result](Статус%20ответа%20сервера.md) | да |  |
| ticket | Ответ на [COMMAND_TICKET](../Команды/Обработка%20чека/Обработка%20чека.md) | [TicketResponse](../Команды/Обработка%20чека/Ответ%20на%20чек.md) | обязательно только в ответ на указанную команду, игнорируется в остальных случаях |  |
| report | Ответ на [COMMAND_REPORT](../Команды/Отправка%20и%20получение%20отчетов/Отправка%20и%20получение%20отчетов.md), [COMMAND_CLOSE_SHIFT](../Команды/Закрытие%20смены/Закрытие%20смены.md), [COMMAND_INFO](../Команды/Инициализация/Инициализация.md) | [ReportResponse](../Команды/Отправка%20и%20получение%20отчетов/Ответ%20сервера%20с%20отчетом.md) | обязательно только в ответ на указанные команды, игнорируется в остальных случаях |  |
| nomenclature | Ответ на [COMMAND_NOMENCLATURE](../Команды/Получение%20номенклатуры/Получение%20номенклатуры.md) | [NomenclatureResponse](../Команды/Получение%20номенклатуры/Ответ%20сервера%20с%20номенклатурой.md) | обязательно только в ответ на указанную команду, игнорируется в остальных случаях |  |
| service | Системная часть | [ServiceResponse](../Команды/Служебная%20часть%20сообщений/Служебный%20ответ%20сервера.md) | нет | см. [ServiceResponse](../Команды/Служебная%20часть%20сообщений/Служебный%20ответ%20сервера.md) |
| auth | Ответ на [COMMAND_AUTH](../Команды/Авторизация/Авторизация.md) | [AuthResponse](../Команды/Авторизация/Ответ%20авторизации.md) | обязательно только в ответ на указанную команду, игнорируется в остальных случаях |  |

> [!NOTE]
> См. подробное описание структуры в файле [Response](Структура%20ответа%20сервера.md).

### Спецификация на уровне Protobuf

Имя файла: [message.proto](../../proto/message.proto)

```protobuf
message Response {
  required CommandTypeEnum command = 1;
  required Result result = 2;
  optional TicketResponse ticket = 3; // required при command == COMMAND_TICKET
  optional ReportResponse report = 4; // required при command == COMMAND_CLOSE_SHIFT || command == COMMAND_REPORT || command == COMMAND_INFO
  optional NomenclatureResponse nomenclature = 5; // required при command == COMMAND_NOMENCLATURE
  optional ServiceResponse service = 6; // required при command == COMMAND_INFO
  optional AuthResponse auth = 7; // required при command == COMMAND_AUTH
}
```
